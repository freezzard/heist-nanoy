The Gilded Vault — an original top-down stealth heist game in pure JavaScript and canvas. Slip the thief Wren through the Vane Museum of Wonders: read the guards' sweeping vision cones and the rotating cameras, keep the alarm meter down, pick the vault lock, lift the Celestine Crown and reach the getaway van. Five rooms, two crawl ducts, a 3-use camera EMP, seven named treasures, synthesized WebAudio sound — no build step, no network, everything drawn from code.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 — or serve the game/ folder with any static file server
```
